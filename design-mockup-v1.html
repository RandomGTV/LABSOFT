LabSoft — visual design proposal

Native Windows app (PyQt) · offline · single database file · mixed medical + analytical lab

2 · Result entry — where auto-calculation happens

One screen, keyboard-driven. You type raw values into the white boxes and tab down. Grey dashed boxes fill themselves in from formulas. Flags appear the instant a value leaves the box — no "Calculate" button to remember.

After Verify & make PDF, this dialog appears. The PDF is already written to disk and already copied to the clipboard; WhatsApp opens on the right number with the message typed. You press Ctrl+V then Enter.

The job is stamped Sent ✓ with date and time, so the work queue and the audit log both know it went out. Message wording is editable in Settings. This same code path swaps to the WhatsApp Business API later without touching anything else.
